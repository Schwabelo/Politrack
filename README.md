# Polytrack
Polytrack is a racing game based off of Trackmania. The game is developed by Kodub and is active on Itch.io. This is version 0.4 of Polytrack, and new updates will not be posted because I am lazy.

## Standalone 0.6.3 build

`build_standalone_0_6_3.py` downloads the official PolyTrack 0.6.3 web build (official + community tracks) and
packs it into a single offline `polytrack_0.6.3.html`. The leaderboard, Track of the Week and other server
features need Kodub's servers and are not included.

This is an unofficial reupload, not affiliated with or endorsed by Kodub.com, CrazyGames, Poki or itch.io.
The original game is by [Kodub.com](https://www.kodub.com); play the official version at
[CrazyGames](https://www.crazygames.com/game/polytrack). It is non-commercial and subject to the
[PolyTrack Terms of Service](https://www.kodub.com/terms/polytrack); the game's own "unofficial version"
